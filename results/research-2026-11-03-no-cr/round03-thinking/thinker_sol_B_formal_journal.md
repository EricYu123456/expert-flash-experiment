### Higher-order cohorts can differ from pairwise coactivation

For one pool group g, let T_g be the original experts that request it. Its expected read event is `Pr(S intersects T_g)`, not `sum_e Pr(e selected)*m[e,g]`. Pairwise inclusion-exclusion is exact only when no relevant triple/higher overlap can occur, or the route distribution supplies special structure.

A fixed-K constructive example uses six experts in three pairs `(a0,a1),(b0,b1),(c0,c1)` and selects one from each pair. Even-parity cohorts `{000,011,101,110}` and odd-parity cohorts `{001,010,100,111}`, each uniform, have identical single and pairwise co-selection probabilities. For a group requested by `{a0,b0,c0}`, the probability of any request is1 versus3/4 because only the odd distribution contains111. Thus full cohorts can contain relevant information absent from pairwise statistics. This is an existence example, not evidence that real routing has a material higher-order gap. If the matched pairwise/coactivation control reaches the same quality/page frontier, the new full-cohort machinery has no established value.

### The true learning burden has to be stated

Tying arbitrary pretrained GU rows is approximate; retaining I atoms/expert does not imply retaining its I original features. A learned nonlinear dictionary plus supports and private Down is a nonconvex reconstruction problem, not the previous cheap ridge fit. Fixed teacher-atom libraries with Down ridge are a valid **restricted** family, but a failure cannot refute freely learned GU pools. A full-pool ridge fit is not an unconditional held-out upper bound on sparse-support quality, because regularization/variance can make a subset generalize better. A natural positive must survive original low-bit source quality, rare-expert and decode states, support hardening and actual deployment quantization. No teacher-query/sample/training budget is assumed free.

Primary prior already covers modules/masks: [ModularMoE](https://aclanthology.org/2026.findings-acl.174.pdf) groups dense FFN neurons into shared modules and learns task-specific fixed-cardinality combinations; its reported activation/context and task routing differ from this fixed pretrained expert-cohort compression. ### Feature equality is not automatically quantized-input equality

The conservative first numeric construction retains one shared GU input quantization and computes each requested raw pool feature once. Host then assembles each expert's ordered I-feature vector and applies its own declared **full-I dynamic A8** quantizer before expert-private Down. Different expert support sets can have different maxima, so shared raw h does not imply identical qh codes/scales. This construction keeps the normal per-expert Down vector rather than assuming a new per-group partial-accumulation command. It cannot claim an automatic128-neuron GU→Down frontier; an expert becomes Down-ready only when all its requested groups are ready and its scale is known.

A per-T128 block-A8 variant could share quantized group inputs, but would introduce group scales, more partial outputs/rescaling/reduction and a different numerical family. It is not chosen for free. Native Q4_K×Q8_K additionally has256-input constraints and its own source F32 chains; the previous A journal's arithmetic warnings remain relevant if that format is selected. A new row-global signed-W4 student would instead have a simple nibble expansion/row-scale ABI but needs independent quality qualification against original native mixed-bit source. Neither a W8 teacher nor W8 deployment is a substitute for that source baseline.

### Source precision can reverse the apparent page saving

In an illustrative uniform nativeQ4_K source, original dense weight payload is `3*(144/256)*HKI=1.6875HKI` bytes. A row-global W8 student needs `H(2U+KI)` before its scales, so fewer raw bytes require `U<0.34375KI`; for K8 this is U<2.75I. The analytic independent-support M4I union≈3.6I does **not** meet that threshold. With Q4_K GU and Q6_K Down the source coefficient-byte multiplier is `2*(144/256)+210/256=1.9453125`; the analogous W8 threshold is U<0.47265625KI. These are precision-specific toy inequalities, not actual tensor-type reads. They show why W8-vs-W8 only is an inadequate performance attribution. A declared student precision and actual native source control must be frozen before candidate trials, including their scales and PE service.

At H2048/T128, a raw W8 paired-GU group has524,288B=32 logical16KiB pages. A row-global signedW4 paired group has262,144B=16 pages before row scales and can be evenly assigned one page/chip in a simple16-chip construction. A Q4_K group has294,912B=18 dense pages, but whole-row, per-chip and cross-codeword restrictions can require other packing. **No version is one page**. A static striped equal-group layout can make wave cost mostly a rounded union-cardinality function; a genuine imbalance-aware objective must expose its distinct mapping consequences instead of relabelling scalar union size as measured latency.

### Finite training needs a real warm start and active learning of excluded groups

Root's good-faith proposal—seed M4I from four representative original nonlinear GU expansions, warm with smooth groups and full private DownM, then harden to sI and fine-tune—is a sensible finite family to examine. It does not promise that four source expansions span all original expert functions. Four seeds selected using FIT-only router/coactivation medoids are reproducible and cheap, but the selection is a heuristic rather than a functional redundancy guarantee. All competing objectives must use identical seeds, updates, teacher rows and transient parameter budget.

Warmup has a concrete gradient issue. With output `D_e (m_e ⊙ h)` and D_e initialized zero for a group, that group's mask gradient is initially zero; hard TopK plus zero inactive D cannot discover useful excluded groups. A dense/smooth warmup with nonzero trained private DownM, followed by explicit hard-support fine-tuning, pays that search cost. A fixed teacher-library plus Down ridge is cheaper but is a different restricted operator family; its negative must not reject freely trained GU. Full DownM transient storage/optimizer/compute and hardening loss must be counted, rather than treating final H×I storage as the entire training footprint.

One fair loss decomposition is router-weighted combined teacher-output reconstruction **plus** a per-expert anchor on natural routed and predeclared rare-expert-floor rows. Both candidate and additive/pairwise controls must have the same combined-output loss, live alpha values, anchor normalization and training budget; otherwise cancellation-aware fitting is confounded with the page-union objective. Teacher outputs from original source numerics versus canonicalW8 need an explicit bridge. Per-token normalization by an almost-zero output norm is avoidable; fixed FIT-derived normalization and a declared zero-energy rule are safer. Source/GU target or initialization queries are paid, not presumed cached by R2.

### Training resource and initialization accounting

Full private DownM has2,147,483,648B F32 parameters for the OLM shape and2,952,790,016B for Deep. Parameters+gradient+two Adam moments alone are about8.59/11.81GB, before GU, source teacher, batches and allocator overhead. Research training RAM is explicitly separate from an8GB deployment budget. Original3KHI is50.331648M/51.904512M, so this warmup is approximately1.67/1.78× original forward work, before gradients and source-label generation. Querying or training all E outputs at every x is not an innocent anchor; it multiplies privateDown work and should be replaced by a bounded natural-route plus declared rare-expert-floor recipe if that is the selected method.

A stronger finite seed alternative to four full experts is to select M4I **actual paired source rows** using a fixed low-dimensional joint-G/U sketch and a bounded medoid/minibatch clustering pass, then form T128 groups. This can preserve diversity from more than four original experts, but adds source reads/projection/search work and still gives no quality guarantee. Do not average or freely normalize gate rows as though SiLU were homogeneous: gate magnitude affects the function. Up rescaling/sign can sometimes be compensated by Down in real arithmetic, but the actual quantizer/float contract still changes. This alternative and four function-medoid experts must not be tried and selected on held-out quality after the fact; choose one finite recipe before experiment release.

The inspected [Mixture-of-Masks](https://aclanthology.org/2025.acl-long.768.pdf) begins from a function-preserving dense model and uses substantial continued training. Its positive result supports the plausibility of gradual masks but not the claim that a four-source pool recovers64 already independent experts from a tiny layerwise dataset. Our required training/data/convergence budget must stand on its own. Undertraining, large hardening loss or rising learning curves are not evidence that every GU-only shared pool is impossible.

This is not the same MoE/NAND problem, but consumes generic “learn overlap with a regularizer” novelty. A coactivation-weighted version of such a pairwise loss is a necessary simple control for the cohort objective. Root supplies a concrete conditional W8 layout: H2048,T128 makes one GU group512KiB=32pages, striped16chips with2pages/chip. Thus almost all16 slots are touched despite a union of about28.8groups. These are **analytic toy support draws**, not real routing. A T256 coarsening control is essential. Same M and sI, requesting complete paired groups gives fewer support choices than selecting T128 halves; it need not attain the same quality. For any candidate T128 support, taking its pair closure includes its function by setting additional Down columns to zero. ### Soft gate amplitude can fake savings; exact support budgets and hard costs matter

For `D_e*(m_e ⊙ h)`, scaling a nonzero group mask down while scaling its D columns up leaves the real output unchanged. A soft union proxy can then report a false reduction. Down norm regularization limits this gauge escape but does not make the proxy an actual deployment cost. A valid recipe must report exact hardened supports/pages; use a declared hard-cardinality forward or explicitly separate dense warmup from final hard-top-q fine-tuning, with nonzero/learnable inactive Down search. All controls get the same support-optimizer and warmup information.

The wave-coverage objective has an additional optimization difficulty: at nearly full union, moving one expert's group may not deactivate any slot. Hard coverage derivatives vanish if other selected experts still request the slot. Independent Bernoulli-style soft coverage may provide gradients but is only a surrogate; its probabilities are not independent exact inclusion probabilities for a fixed-cardinality subset. A hard-forward/soft-gradient or score-function estimator must be named and costed, rather than claiming exact differentiable wave optimization. Its true hard TRAIN cost should be logged at predeclared checkpoints. A pairwise/coactivation loss can give denser guidance and might match or exceed the proposed higher-order learner; that is a legitimate negative region.

### Exact best post-pair layout is tractable under this finite layout contract

Fix learned supports and let A_g(x) indicate that the actual selected expert cohort requests group g. A physical pair(a,b) is read with probability `p_a+p_b-p_ab`, where p_g=E[A_g] and p_ab=E[A_a A_b]. Since every group is paired once, total expected slots is `sum_g p_g - sum_(a,b paired) p_ab`. Thus **maximum-weight perfect matching** on G32/44 group nodes exactly minimizes expected pair-slot waves under this stated construction. The weights are TRAIN-only **group activation events derived from complete cohorts**, not expert-pair frequencies. Tie-breaking and train/score separation still need freezing.

All arms should receive this exact finite-layout postoptimization, and the candidate can use a bounded alternating mask/weight update→re-pair schedule. This does not prove global joint optimization or optimal arbitrary NAND mapping. It does avoid comparing the candidate against a weak heuristic layout, and makes the residual learning advantage identifiable. Group-event pairwise matching does not invalidate Block01's expert-marginal parity example: computing the group events already requires its actual cohort/support intersections.

Critic identifies an important resource counterexample: for G32 W8 groups, store every C(32,2)=496 legal1MiB pair macro. This costs496MiB GU/layer, lets runtime pair any active group set into legal macros, and can reach `ceil(Ugroups/2)` sensing events, overreading one partner when odd. Therefore fixed-pair saturation cannot be called a universal NAND necessity. The shared-GU cohort-union question survives, because actually computing fewer shared nonlinear functions still changes necessary work; the claim must be tested against replication/capacity choices. If replicas remove the wave-aware learner's gain and a simpler union-cardinality/shared model attains the same quality/capacity point, the physical-specific claim is weakened. ### A named bounded optimizer should contain one coordinated move stage

At most16/22 slot proposals are considered for the initial shapes; no repeated sweep triggered by validation or a favorable quality result.
