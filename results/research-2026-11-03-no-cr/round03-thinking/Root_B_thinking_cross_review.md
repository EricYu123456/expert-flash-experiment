## Conditional W8 physical-pair example

For H2048/T128 one GU group contains512KiB rawW8, or32 pages. Striping over16chips gives2pages/chip; two fixed groups can occupy complementary pairs of planes at the same compatible block/WL. One occupied physical pair costs one ordinary sensing wave under this conditional mapping. This is a construction hypothesis, not native AiF support or a measured28us complete service. Scales, descriptor, ECC, input retention and output lifetimes are separately paid.

For a toy independent uniform8-of32 support on each selected expert, avoiding a given pair has probability C(30,8)/C(32,8)=552/992; for K8 the expected occupied pair count is16*(1-(552/992)^8), almost16. Fine union counts alone therefore miss the wave cost. No true routing probability is asserted.

With supports fixed, optimal static pairing minimizes sum_pairs(Pa+Pb-Pab), hence maximizes sum_pairs Pab over a perfect matching. A strong post-layout control can solve this exact pairing objective; expert-pair statistics and group-need-pair statistics are distinct. A coarseT256 control receives fine submasks/implicit zero capability when comparing identical families; allowing additional nonzero Down columns changes its capacity/compute budget. Index permutation symmetry alone is not a new hardware primitive.
