## Provisional priority: two questions, neither adopted

**A. A source-quantization-block / NAND-wave / finite-LUT frontier.** Preserve the source's nonlinear operations and mixed low-bit function, rather than another unconditional FFN surrogate. Ask whether a finite LUT-window architecture compiled around actual Q4_K/Q6_K block boundaries has a Pareto region against **both** same-format ordinary-load/CPU and same-area direct low-bit MACs. A nibble expander, input-derived LUT generator or ordinary fusion alone is not a contribution. This is the clearest small-hardware question so far, but the counterexample is strong: a native4×8 multiplier is already cheap, while lookup ports, table generation, metadata and partial states can cost more.

**G. Token-conditioned ordinary sensing/ECC effort.** Preserve all experts' G/U/SiLU/Down operators and change a physical read-effort action, using actual live alpha and quantized Down input available before that read. ## Seven distinct mechanism screens

### A. Source-faithful compressed-domain arithmetic and legal producer/consumer quanta — exact goal

**Necessary change:** remove expansion of mixed source quantization into raw W8, and potentially replace a whole-I nonlinear/A8 barrier with the source's actual independent quantization-block boundaries. This does not remove SiLU or assume a low-rank nonlinear function. Q4_K uses256 weights/144B with scale/min substructure; Q6_K uses256/210B with signed subscales. Neither is a plain signed nibble. Input quantization and every block/lane reduction must be part of the declared function. Exactness means reproducing the chosen pinned arithmetic, not merely decoding the same real-valued weights.

**Placement:** compressed code blocks plus metadata remain in ordinary-read NAND pages; host computes the pinned input quantizer and original nonlinear tile; a finite on-die table/window or low-bit decoder feeds integer partials. Source FP32 scale/lane continuation must be held explicitly or returned to host in its original order. Final per-row results and live-alpha aggregation remain ordered. GU can share its one input-derived table across K ready experts; each expert's Down input/table is private.

**A nontrivial narrow proposition:** choose input window T and row count n jointly with page/wave size, table ports and live partial-state capacity, instead of requiring a full-H activation LUT. For a g4 subset LUT with I16 entries, storage is8T bytes; T256 is2KiB. A64KiB wave holds at most448 complete Q4_K blocks (64,512B) or312 Q6_K blocks (65,520B). One I32 partial per row would be1792/1248B respectively, **but that is not the total source-exact state**: per-subblock scales, FP32 lanes, table generator registers, ECC staging and FIFO also count. A full g4 table is32KiB for H4096 and112KiB for Down width14336. This makes a bounded window/continuation tradeoff concrete. These are shape calculations only.

**Fair ordinary baseline:** exact same source-format blocks, prefetch/frontiers, metadata residency, host budget and CPU T-MAC/CodeGEMM-type kernels. Also compare the same silicon/clock/SRAM/ports spent on more native low-bit MACs plus nibble/scale decoding. Ordinary-load can exploit the same tile readiness; dependency reduction is not exclusive to PIM.

**Counterexamples:** g4/W4 requires roughly one LUT lookup per weight, so there is no automatic instruction-count advantage. Many lookup ports may need replicated SRAM or large muxes. Source reduction order can require far more state than an I32 accumulator. Finer GU tiles can increase rounded NAND waves; a producer/consumer pipeline with more waves can lose to a whole-phase schedule. Global A8 may be an artifact of the prior numerical reference rather than a source limitation. Original OLM mixed-Q4 can plausibly fit host; a larger no-shared shape may matter, but that does not authorize a model download.

**Minimum falsification, after a future adoption/release:** first a symbolic/physical compiler certificate for the true formats, lifetime and page count, then generated-value source arithmetic/area-service closure against direct MACs. Only if a nonempty region survives should actual same-quality/full-model studies be considered. New primitives are a finite table/partial register window and an explicit typed quantized-block instruction/continuation, not assumed spare PB ports. [T-MAC](https://arxiv.org/abs/2407.00088), [CodeGEMM](https://arxiv.org/abs/2512.17970) and [LUT-LLM](https://arxiv.org/abs/2511.06174) directly cover substantial lookup computation. Root/Terra additionally identified PALUTE2606.08891 on near-memory LUT generation. Therefore the generator/lookup idea itself is not novel. SLIM's fused GU/Down also blocks generic fusion claims.

### B. Decode-late exact arithmetic repair — exact, standalone thought rejection

**Necessary change:** remove the ECC→MAC serial edge. Send raw sensed W8 bits simultaneously to a dot engine and ECC decoder, quarantine integer results, then patch every corrected data-bit contribution before any FP32 scaling/nonlinear consumer commits. For sign-bit coefficient v7=−128 and vb=2^b otherwise, a corrected bit changes a row sum by `(newbit−rawbit)*vb*q_j`. Use sufficient integer range and the baseline decoder's same correction/retry outcome.

**Placement:** raw codeword in bounded on-die staging, input RF, quarantined I32 row results, ECC error-location queue and small repair adder; no new analog primitive and no CR. Ordinary-load gets the same ECC concurrency, but needs corrected weights or equivalent patch/recompute before host results commit. No full-model headroom is assumed.

**Decisive prior:** EPO [EP4016304A1, paragraphs0019–0023](https://data.epo.org/publication-server/rest/v1.2/publication-dates/20220622/patents/EP4016304NWA1/document.pdf) already describes concurrent memory compute/ECC and correcting computed results using decoded error locations. This directly consumes the basic mechanism. It remains a useful strong architecture baseline, not a new candidate. A generated exhaustive-error-position test and real ECC/PE timing would be needed if used as a component; neither is run here. Small changes are error-location routing/repair and bounded quarantine, not free overlap.

### C. Certified head-page cancellation and exact sampling — exact relative to a specified head/sampler

**Necessary change:** avoid computing/scanning every LM-head weight row when the requested operation is greedy argmax or categorical sampling, rather than full log probabilities. A page hierarchy stores query-evaluable bounds; an incumbent winner cancels a page only when every uncomputed logit is bounded below it. Gumbel perturbations can convert exact categorical sampling to a certified maximum problem; exact top-p, finite-PRNG behavior and floating source-dot envelopes require separate contracts.

**Placement:** head pages in NAND, small hierarchy/bounds and random seeds on host, hidden query and selected-head computation in PE or CPU; result is a certified token/score, not all logits. No shared expert is used. Strong ordinary-load/host implementations get the identical index and bounds, and the head may be fully resident.

**Counterexample:** high-dimensional norm bounds can be almost useless; hierarchy work and extra tiny reads can exceed a dense sweep. This does not accelerate full-NLL evaluation requiring every logit. Established [A* Sampling](https://arxiv.org/abs/1411.0030) already avoids irrelevant Gumbel evaluations using bounds; [exact MIPS optimization](https://arxiv.org/abs/1706.01449) is also direct prior. The head's fraction of whole-model critical service must first justify any work. A bounded future screen would compare conservative page-bound coverage/total work with an indexed host-resident head, not run a search algorithm and count only canceled bytes. The small change would be a page-score/argmax instruction or comparator; the index/sampling theory is not new. Not currently a leading candidate.

### D. Lossless linear-program / grammar representation of integer matrices — exact integer goal

**Necessary change:** store an exact repeated-subvector/addition DAG, compute each reusable input-weight subexpression once and refer to its integer partials, instead of reading/decompressing every W8 coefficient independently. This is lossless algebraic compression, not low rank plus omitted residuals. Every exception remains stored and evaluated.

**Placement:** grammar/dictionary instructions in NAND, bounded nonterminal integer values/input in SRAM, final row sums in I32/I64; row scales apply only after the declared exact integer result. Same-format CPU gets the same grammar and reuse. A small instruction decoder, bounded stack/cache and adds would replace some MAC traffic.

**Counterexample/prior:** weights may have too little exact repetition; dictionary indices/exception streams can exceed scalar entropy coding, and dependencies/psum spills can erase the savings. [Lossless grammar-compressed MVM](https://arxiv.org/abs/2203.14540) already studies this mechanism. [Conditional impossibility results](https://research.ibm.com/publications/impossibility-results-for-grammar-compressed-linear-algebra) caution that compression ratio alone need not give proportional compute savings. Minimum future screen would compare an exact format's pages plus bounded execution against a streaming lossless decoder and raw same-format ordinary-load. No general-new mechanism is identified here; do not spend an experiment opportunity simply measuring another codec.

### E. Nonlinear interaction representation instead of a conditional affine FFN — approximate

**Necessary change:** preserve a compact multiplicative nonlinear core, e.g. phi(x)=SiLU(A Px) tensor-product B Px, and read a corresponding output interaction tensor once. The goal is to retain cross-coordinate curvature that R2's affine maps dropped; no claim that this is exact or that a finite feature count preserves the source model.

**Placement:** shared input projection/small nonlinear core on host, compressed interaction/output weights in NAND, features in input RF, output sums in PE/host. A pre-experiment arithmetic/storage analysis must count the quadratic feature dimension and extra host work. Ordinary-load can evaluate the same student; small enough models may reside entirely on host.

**Hard controls/counterexamples:** original mixed-low-bit MoE, lower-K/width at matched quality, nonlinear projected GU plus original Down, MoLAE/common-output lifts, tensor/structured MoE and equal-capacity nonlinear students. A low-dimensional nonlinear student is not new merely because it beats a local linear fit. Product-feature dimension can erase weight savings, and reducing nonlinear features can fail all64 just as dramatically. No small hardware change beyond a declared feature-input path is needed, which further weakens an in-flash-specific novelty claim. A legitimate future falsification would be a fixed full-coverage natural-text quality/active-bytes screen with adequate training, not partial8 output MSE. This is a macro architecture pool, not an R2 rank/guard/data repair or adopted method.

### F. Conditional depth or exact self-verification changes work per emitted token — approximate depth / exact verification variant

**Necessary change:** skip whole operator/layer loads under a trained depth policy, or amortize a full target's remaining layers over multiple verified tokens. This attacks number of required full operators, rather than their placement. Weights stay in NAND; draft/exit state and independent KV/verification bookkeeping stay in host; finite multi-input partial states are charged.

**Hard controls:** [Mixture-of-Depths](https://arxiv.org/abs/2404.02258), [LayerSkip](https://arxiv.org/abs/2404.16710), SLIM ordinary-read multi-input GEMM, all fixed verification chunks/horizons and same-area ordinary-load CPU batched verification. The source target is preserved only by a correct exact-verification protocol; a trained early-exit model itself changes the model and needs quality tests. Rejected suffix work, routed expert unions and input-ready timing all count.

**Counterexample:** ordinary verification batching already reuses weights; low acceptance, expert-union growth and extra KV erase the benefit. Previous generic frontier exploration has not identified a new PB/causal primitive. A future claim needs a concrete schedule/capability not already granted to these controls, then exact accepted-token and bounded-buffer tests. No such missing primitive has been found in this block; do not restart the old frontier under a new name.

### G. Functional significance controls ordinary sensing/ECC effort — approximate physical operation

**Necessary change:** all nonlinear model operations remain, but choose a legal ordinary-read effort/time/retry/ECC action for a Down page using its current true alpha and q_z. A fast read may retain all nominal weight bits while accepting a calibrated, protected error distribution, rather than deliberately reducing the model's precision. Storage bit/cell labeling and critical metadata protection are part of the representation; a single exponent/scale/sign error can dominate many low-bit coefficient errors.

**Placement:** original quantized pages and their protection metadata in NAND, read-effort lookup/controller on host/device, current per-expert q_z in RF, normal PE sums plus declared error handling. No shared expert or CR/precharge retention is used. Output bias/quality cannot be inferred from an independent Bernoulli model when real errors are biased/bursty/correlated.

For a simplified row-scaled integer Down, Critic's strongest cheap control is explicit: conditioned on independent zero-mean coefficient errors, `E||delta_y||² = alpha²*sx²*sum_j sw_j²*sum_k q_z,k²*Var(error_jk(action))`. A page action can therefore use alpha² times that page's input-column energy and its calibrated error-effort curve; no random sketch or learned selector is necessary for this model. If the true curve is effectively constant or cheap allocation matches a fancier policy, the proposed complexity has no value. Different expert errors/correlations and floating boundaries must be modeled honestly, not called certified by this equation.

**Direct physical controls:** [AR²](https://arxiv.org/abs/2104.09611) adjusts read latency using ECC margin; AiF itself discusses model error tolerance/ECC. [Graceful CNN degradation in uncorrected flash](https://doi.org/10.1145/3747298) already combines importance-aware cell labeling and variable protection. DPA-style alpha/activation-norm precision allocation, static strongest effort, same-page cheap variance allocation, and same-quality source low-bit CPU/ordinary-load are required. Give ordinary-load the same legal read-effort/UEP/error handling. If ECC succeeds it already returns exact bytes: one must say whether the gain is fewer retries/iterations or explicitly allowed uncorrected bytes, not conflate them.

**Minimum falsifiable next evidence, not an experiment release:** a primary-source ordinary nonCR timing/control contract plus measured joint tR/error-location/retention/ECC-tail curves that bracket a useful region. Then a fixed whole-model quality/noise experiment could test one policy and strong controls; synthetic bit flips alone cannot establish the faster physical read. Small changes might be controller timing/effort selection and metadata protection, but are unproven until the actual command/circuit capability is identified. Generic model-sensitivity migration to a new action is a narrow potential contribution, not automatically a paper.

### A2. Train shared nonlinear GU **groups** for the route-union page objective — strongest current question

Let pool atom j be `phi_j(x)=SiLU(g_j^T x)*(u_j^T x)`. Each original expert keeps a fixed requested set `A_e` and its own Down columns, so the original live router selects a **union** `U(x)=union_(e selected) A_e`; compute every requested atom once. Approximate sharing of originally different g/u rows requires post-training joint reconstruction or distillation. It is not exact just because row cosine similarity is high. Existing original shared experts are independent functions and are not assumed in this construction.

The genuinely work-changing event is tying two originally distinct nonlinear GU functions to one learned function, not caching two separate dense experts. Store paired GU rows in ordinary NAND group pages; retain the original expert-specific Down matrices or an explicitly fitted reduced-width version in separate pages. Input quantization/host RF feed the requested GU groups; the host holds pool activations and assembles each expert's ordered Down input; die/host partial sums and source numeric order are paid. A new support/group command may reduce dispatch overhead, but no analog or CR primitive is needed. Ordinary-load gets exactly the same pool, supports, page groups, union deduplication and early readiness; this mechanism may improve both paths and does not alone establish in-flash necessity.

The narrow joint-training question is whether a **hard group support** per expert can reduce actual whole-page union cost at matched free-running quality and capacity beyond independently pruned neurons/repacked experts. A source-only objective is `E_route sum_p 1{some selected e requests pool page p}` with the true support budget, GU/Down numerical graph and page capacity, rather than summing per-expert selected neurons. This is a different optimization variable from merely placing a fixed graph: it changes which nonlinear functions experts share. Train route-union cost and reconstruction jointly, then compare with the same learned pool/support budget trained for additive neuron cost and optimally repacked. No empirical support or hit rate is assumed.

If every expert uses I atoms and the selected union has u distinct atoms, equal-byte ideal GU+unchanged-Down payload is `(2u+KI)H`, versus original `3KIH`. This isolated weight-work expression includes neither pages nor host/time. No overlap u=KI gives no GU saving. All K experts sharing exactly the same I features gives a ratio `3K/(K+2)` but can destroy specialization. Very fragmented u can produce more page reads than copied compact per-expert GU. An always-hot globally shared pool may fit host and defeat a claimed need for flash compute; inclusive8GB and samecache remain mandatory. Fully dense per-expert Down can also become the dominant unsaved path.

The strongest nearby sources are explicit. [LLaMA-MoE](https://aclanthology.org/2024.emnlp-main.890.pdf) already has neuron-sharing constructions. [DERN](https://aclanthology.org/2025.findings-emnlp.820.pdf) aligns/merges neuron triplets from existing experts, though it changes the retained expert bank. [PCoMoE](https://aclanthology.org/2026.emnlp-main.2048.pdf), §4.3, already evaluates one nonlinear source expansion once for several output projections. Its finer-source/sliced version is a necessary strong comparison, not just the whole-expert configuration. [MoNE](https://arxiv.org/html/2510.05781v1) makes neuron-level sparsity a direct pruning/training control. These references consume “shared nonlinear atoms” as a standalone novelty claim.

**Important collapse control:** if Down is further constrained to `d_ej=c_ej*d_j` with scalar c, then `y=sum_j d_j phi_j(x)*(sum_e alpha_e c_ej)`. That is a router-conditioned neuron pool with shared output atoms, not a reason to store K copies of the same output columns. Give the ordinary/shared-output control this algebraic ability, with actual quantization/round order. Conversely, with genuinely different dense d_ej, premerging output **vectors** requires reading their coefficients and is not free.

My judgement: **worth a bounded formal research question only if the claim is the new learned hard-support/physical-union frontier**, and only after checking ModularMoE/PCoMoE at the same group granularity. Generic sharing plus a coverage regularizer is not automatically a paper. It has a clear possible positive mechanism, unlike rejected A's purely implementation-constant difference, but it remains unresolved whether a same-capability ordinary model already fully captures the contribution. A minimum future falsifier would test function reconstruction and actual held-out group/page unions together on overlapping expert supports, then free-running quality. Pure union coverage, training loss, two distinct-node experts, or one representative expert cannot identify the mechanism.

### B2. Linear measurements of the **true combined nonlinear output**, followed by one nonlinear decoder — independent alternative

Preserve every selected expert's original GU/SiLU computation. Choose a common linear measurement `S:R^H→R^r`, store compressed Down matrices `V_e=S D_e`, and obtain `s=sum_e alpha_e V_e h_e = S y` in real arithmetic. A small shared **nonlinear** host decoder `d(s)` reconstructs the combined layer update. This changes the necessary Down coefficients from H×I to r×I; it does not replace each whole FFN with an input-affine map and does not eliminate its original nonlinear representation. The decoder must be trained on the actual combined live-alpha output distribution. Training separate per-expert autoencoders and asserting `d(sum alpha s_e)=sum alpha d(s_e)` is invalid.

Weights GU and V_e live in NAND with ordinary reads; h_e is produced by the original nonlinear path on host, then posted for its private Down measurement. The r-output partials/alpha accumulator live on host or explicitly specified die state; one decoder and its weights live in host memory and are billed. No shared expert is required. New numeric quantization of V_e and all arithmetic are approximate relative to the source, so the real-valued identity `s=Sy` is not a bit-equivalence claim. The decoder could have a linear skip plus a small nonlinear residual; it may not secretly include a full expert bank or an input-to-full-output substitute of unbounded size.

This is a nonlinear **output-manifold** hypothesis with an information-theoretic failure condition. For fixed S, the minimum achievable decoder MSE is `E Var(Y | S Y)`; two relevant outputs with the same measurements and different missing components cannot both be reconstructed. For a jointly Gaussian output distribution, the optimal squared-error conditional mean is linear, so this nonlinear decoder cannot improve over the corresponding optimal linear reconstruction. A useful region therefore requires real non-Gaussian/curved conditional structure, not just higher decoder parameter count. A possible future first falsifier is a held-out combined-output linear-versus-nonlinear reconstruction at identical measurement rank/bytes, with matched higher-rank linear lifts, before any hardware claim. This is a specified measured target, not “full KD might win.”

For uniform formats and equal GU/Down dimensions, even zero-cost perfect decoding removes at most `(H-r)/(3H)` of dense FFN weight work, approaching only one-third. Mixed source precisions change this fraction. NAND rounding, V quantization, decoder host service and GU bottlenecks reduce benefit. [MoLAE](https://arxiv.org/html/2503.23100v2) and global/group-shared output lifts are mandatory strong nearby controls; the nonlinear decoder's generic autoencoder idea is established ML, and this bounded search has **not** established a new MoE/NAND contribution. Compare a same-host-budget higher-rank linear lift, same-parameter nonlinear latent expert, original mixed low bit/lower width, and identical ordinary-load/CPU execution of the compressed representation. No claim of full64 quality, sufficient r, or speed is made.

My judgement: more informative than another affine bank and mechanistically distinct from GU sharing, but lower priority than A2 because GU remains untouched and the saved Down fraction may be too small. It is not yet ready for adoption; a direct-prior search and a concrete host-decoder cost/format contract must precede a formal clock. It is not a license to revive R2's failed rank/data recipe.

### C2. Exact shared integer subexpression DAG across selected experts — different mechanism, weak novelty

Compile quantized GU/Down blocks into a lossless addition/shift dictionary: compute a reused input linear combination once, then refer to it in several original output rows. Every exception remains, so arbitrary full-rank matrices can still be represented exactly. Operations/dictionary pages reside in NAND, input and bounded nonterminal I32/I64 values in explicitly added SRAM, output sums in declared integer accumulators, followed by the original scale/round contract. Ordinary-load executes the same compressed program; no shared expert or CR is used.

This can actually remove coefficient reads and repeated integer operations, but it is not a newly invented LUT or a low-rank approximation. [Common Subexpression-based Compression and Multiplication of Sparse Constant Matrices](https://arxiv.org/abs/2303.16106) already jointly compresses/evaluates such DAGs; the earlier grammar-compressed MVM reference in direction D is also direct. Random or high-entropy weight rows may require a larger program than the original native low-bit stream, and long dependencies/state spills can erase savings. Exact integer identity must still preserve the selected source's later floating chains. Without a new physically grounded compression/evaluation property beyond this known mechanism, I recommend **thought rejection rather than a model probe**. This is an independent mathematical representation, not a second version of the LUT-window candidate.

### D2. Certified final-token refinement that skips full expert/layer work — exact KV obstruction

An optimistic design computes a cheap forward pass and refines only enough expensive expert pages to certify the same final greedy token or Gumbel maximum. Weight-page bounds and selected partial results live on host/die; the original model's exact live states would have to be retained or reconstructed. Ordinary-load receives the same certifier and schedule, and all Lipschitz/interval/numerical metadata must be paid.

The unavoidable counterexample is temporal state: equality of the **current** output token does not imply equality of higher-layer K/V written from changed FFN-dependent hidden states. A subsequent token can attend to these different keys/values and diverge. To claim exact continuation, skipped work influencing future KV generally has to be completed before that KV is used, or an additional exact irrelevance certificate must cover every future use. Lazy recomputation then moves rather than removes the required ordinary pages; the last token is a special case, not a general decoder speedup. This is not repaired by summing layerwise errors and ignoring attention. Approximate layer skipping/self-speculation is a different, prior-rich quality contract. **Thought reject this naked exact shortcut**, rather than counting equal-token accuracy as an exact method.
