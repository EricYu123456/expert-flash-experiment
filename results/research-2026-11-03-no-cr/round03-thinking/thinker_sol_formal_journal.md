Each16KiB plane independently fits113 Q4_K blocks(16,272B) or78 Q6_K blocks(16,380B). Thus unconstrained per-row block packing gives452/312 across4planes. Full-row-format and cross-page carry are separate valid alternatives, not automatically prohibited.

For window-major execution on R rows, the FP32 cross-input-block continuation alone is36R(genericQ4),48R(AVX2Q4), or32R(Q6). For R452 AVX2Q4 this is21,696B, not one I32/row(1808B). Table/input/metadata/ECC/FIFO and row tags remain additional.

If the matrix has O owner rows and uses R-row bands, a tiny-window path must either (i) repost its input/table for every band, (ii) keep full raw Q8_K input and regenerate each window for every band, or (iii) retain more tables. ### Primary prior overlap is specifically relevant

- [LUT Tensor Core, ISCA2025](https://arxiv.org/html/2408.06003v3), §§3.1–3.3, already separates table precompute, fuses it with a previous operator, uses symmetry and precision-dependent LUTs, and schedules tiles by memory size. Its §4.2 evaluates the LUT-versus-MAC/ADD area and precision tradeoff. It does not prove Q4_K/Q6_K source bits or a NAND result; it does consume a generic finite-table/generator/tiling contribution.
- [FIGLUT](https://arxiv.org/html/2503.06862v1), §§II-B/III, already provides affine offsets, variable precision, conflict-free register/MUX readout, half tables and a reusable generator. Its FP/INT numerical and technology choices differ; no reported PPA is transferred to AiF.
- [Geens et al., ISPASS2026](https://arxiv.org/html/2604.25183v1), §§II-C/III–VI, explicitly vary table depth, parallel tables, fetchers and output accumulators, with technology-dependent readout/adder costs. Its ternary/16nm results cannot certify Q4/Q6 NAND PPA, but demonstrate that the remaining generic space/throughput boundary is itself an established study.
- [PALUTE](https://arxiv.org/html/2606.08891v1), §§3.2–3.4, already places generators near memory and coordinates generation, placement and queries. Its actual new physical access is M3D-DRAM MAT querying, which this NAND proposal does not possess. Ordinary sensing followed by a generic LUT engine does not inherit that access capability.
