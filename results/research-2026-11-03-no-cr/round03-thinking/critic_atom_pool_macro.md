# Shared nonlinear atom pool: bounded macro critique

No candidate implementation, model/weight/X/Y/FIT/quality/book/TEST payload, fitting or simulation was read or executed. Root has2 failed experimental methods and8 opportunities; none is consumed here.

The idea has a real work-changing possibility: compute a common nonlinear feature once when multiple selected experts need it. Unlike the rejected native-LUT port, this can reduce actual GU products and reads. It does **not** yet establish a useful pool size, quality, physical-page reduction, NAND necessity or novelty.

## First separate two different model classes

Let the common GU feature be `h_j(x)=SiLU(g_j·x)*(u_j·x)`, expert e have a static support S_e of s atoms, and U be the union size for the actual selected K experts.

**Only GU is common.** If every expert retains its own H-dimensional Down column `d_e,j`, then active coefficient work is proportional to `H*(2U+K*s)`, compared with original `3*K*H*I`, at equal coefficient precision before metadata/page effects. The same h can be computed once, but the K distinct Down columns still have to be fetched/used. If U=Ks, the supposed sharing gain vanishes and the reduction is ordinary width pruning (`s/I`). If U=s, sharing can save GU work, but does not make Down a single shared read. Scalar sparsity inside these full columns is a third representation with separate index and page costs.

**A full nonlinear vector atom is common.** If `d_e,j=c_e,j*d_j`, with a shared output vector d_j and expert-specific scalar c_e,j, the real-arithmetic layer is

`y = Σ_j β_j(x) d_j h_j(x)`, where `β_j(x)=Σ_selected_e α_e(x)c_e,j`.

Now the shared GU and shared Down atom can each be evaluated once per union member. This is a constrained, router-conditioned sparse FFN / neuron-expert model, with signed coefficients allowed when the numerical contract allows them. It is a **more restrictive approximation family** than arbitrary expert Down columns. It cannot borrow the first family's greater expressivity and the second family's smaller Down traffic simultaneously. Floating premerge/reduction/quantization must be declared; this real identity alone is not source-bit exactness.

Neither family relies on an existing always-on shared expert. An original shared branch, if present, remains an independently accounted function.

## Concrete counterexamples and required comparison paths

1. **Disjoint supports.** A union of original expert neurons is an exact real-valued representation with N=EI and s=I, but disjoint supports give U=KI and no reuse. Compressing it requires functional redundancy or approximation, not merely renaming neurons as atoms. Co-selection does not prove shared GU responses or compatible output directions.

2. **Small pool becomes a host model.** For the GU-only family with N≈I and sparse supports close to I, its shared GU plus reduced Down bank can be much smaller than the original MoE. Give optimized same-model all-host/cache execution that small bank. For the full-vector-atom family the complete bank is roughly `3HN + E*s` coefficients rather than `3EHI`; low-bit N small enough for quality may also fit host. Inclusive capacity still pays non-FFN/shared/KV/runtime/scales; fitting the coefficient count is not a measured8GB deployment certificate. If N instead approaches EI to preserve quality, capacity and union work can return toward the original. This is a Goldilocks question, not a universal no-go.

3. **Sparsity that touches every page.** Unstructured atom IDs or sparse Down elements can cause almost all16KiB pages to remain necessary. For a simplified H2048 W4 full-vector atom, three H-vectors are3KiB before quant metadata, so only five whole atoms fit a16KiB page under simple bundling. A scattered union and a clustered union can therefore have very different page counts at identical U. Do not infer sensing waves from scalar support size. Same-format ordinary-load receives the same page groups, duplicate copies, coefficient maps, early router information and cache.

4. **The expert labels may be redundant bookkeeping.** The full-atom model's two-level route can be folded into β above. A direct atom router / equivalent sparse FFN has the same function; a matched nonlinear latent student, common-basis model and original low-bit/width/lower-K paths are concrete strong controls. This algebra does not itself veto a useful learned representation, but it prevents claiming the outer expert bank is physically necessary or forcing controls to repeat shared feature evaluations.

5. **A trainable GU dictionary is not a ridge fit.** Millions of shared nonlinear parameters and their supports require a specified finite training/distillation recipe, representative input states and enough optimization. Fixing teacher GU features and fitting Down is cheaper, but tests that restricted dictionary family. Failure of a small untrained/undertrained pool does not falsify every shared nonlinear dictionary. Conversely, cheap local MSE does not establish free-running or full-model quality. Teacher-query, calibration and optimization costs are part of the method; no repeated rescue until a favorable result.

## Primary precedents and what they do not establish

- [LLaMA-MoE, EMNLP2024 §2.1 and AppendixC](https://aclanthology.org/2024.emnlp-main.890.pdf) explicitly explores overlapping neuron index subsets (`SharingInner`) and shared residual neurons (`SharingInter`) when converting a dense SwiGLU FFN to MoE, followed by continual training. This is strong prior for shared-neuron construction, not evidence that its final pretrained copies remain tied or that it implements the proposed post-training MoE dictionary/union kernel. Its main method actually chooses non-overlapping random partitions.
- [MMoE, Google/KDD2018](https://research.google/pubs/modeling-task-relationships-in-multi-task-learning-with-multi-gate-mixture-of-experts/) already shares expert submodels across tasks with task-specific gates. Treating original experts as tasks and neuron atoms as subexperts is a useful architecture comparison, **our interpretation**, not a claim that this source implemented NAND/SwiGLU compression.
- [MoLAE/MoLE](https://arxiv.org/html/2503.23100v1) shares input/output latent mappings with expert-specific transformations. It is a strong nonlinear compressed control; low-rank linear sharing does not by itself prove arbitrary GU atoms can be tied through SwiGLU.
- [MoNE](https://arxiv.org/html/2510.05781v1) selects neuron experts within original experts using gate activations. It is not proof of cross-expert common atoms; it is a strong work-reduction comparison.
- [DERN](https://arxiv.org/html/2509.10377v1) prunes experts, assigns their neuron segments to retained experts and merges them. [MC-SMoE](https://arxiv.org/abs/2310.01334) aligns neurons, merges expert groups, then compresses. These consume generic neuron alignment/recombination claims but do not establish exactly the proposed tied nonlinear pool with union-once execution. Existing NimbleMoE/group-basis controls remain relevant from the earlier source ledger.

This bounded search establishes neither exact same-method priority nor global absence. A marketing-only shared-neuron-pool repository was also encountered; it provides no verified pretrained-transformer/NAND arithmetic comparison and is not used as a veto or performance source.

## What could warrant a new formal question

The narrow potentially useful gap is **learning shared nonlinear feature groups with an explicit whole-page union cost**, at a finite quality/training/capacity budget, rather than generic common-feature sharing. The scientific unknown is whether adequate quality survives when the pool, supports and grouping actually remove legal NAND pages, and whether that operating point beats the same representation on host plus strong nonlinear compressed baselines. A same-quality point may suffice; it need not beat every architecture or replace every layer before exploration is allowed.

Before adopting even that question, specify whether atoms share GU only or full output vectors, N/s/page group size, the teacher/distillation information, and one named equal-capability nonlinear control. These are model-definition and attribution needs, not a request for new probes or an unlimited grid. Current stance: **not preendorsed; not globally thought-vetoed; zero formal clock**. No source implementation or experiment release follows from this note.

## Root's sharpened GU-only group proposal: finite judgment

Root subsequently specified **GU-only**, hard per-expert group support, expert-specific Down retained, original router, and a training objective based on whole-page union across selected experts. This repairs the family ambiguity above. I support spending a fresh formal≥1800-second thinking interval on that **question**, not implementing it or starting a necessary-quality test yet.

A concrete conditional separation exists. Suppose each selected expert needs two equal-size feature groups: one common nonlinear group C and its private group P_e. Independent expert execution reads2K GU groups; a shared partial pool readsK+1, while retaining every private group and all K expert Down weights. Whole-expansion reuse cannot automatically obtain this saving without discarding some private feature or extracting subgroups. It is not a claim that real pretrained experts have this structure, but it shows a work-changing hypothesis beyond placement or lookup constants. [PCoMoE](https://arxiv.org/html/2609.01024v1), §§4.1–4.3, is nevertheless a strong direct comparator: it composes/reuses whole nonlinear expansions across Down destinations with compatibility routing. Do not mislabel its whole-expansion scope as proof that neuron-group generalizations are impossible or unrelated.

An additive per-expert support penalty can also miss the objective. For fixed expert supports of equal size, two designs can have identical total L0 but different unions for frequent route cohorts. A representative page objective is `E_T Σ_p c_p * 1{some e in T needs data on page p}`. This is a weighted coverage cost, not automatically a new optimization theorem; overlap-aware regularization and coactivation grouping are established ideas. The proposed necessity must be isolated against **the same nonlinear pool trained with independent support/width objectives then optimally laid out**, as well as whole-U reuse / nonlinear latent sharing. If only post hoc layout changes, or those controls choose the same supports/quality/pages, the extra training machinery has no demonstrated value.

Group size must be physical. At H2048 with Q4_K, a256-neuron GU group is589824B (36×16KiB pages), and its256-input Down slice across H outputs is294912B (18 pages) per expert. These are dense shape counts before mapping/wave dependencies; one group is not one page or one wave by definition. Quantizer grouping, partial-output storage, actual chip/plane allocation, metadata and GU→nonlinear→Down readiness must still be legal. The ordinary-loader counterpart gets the identical learned group map and union reuse.

If shared h groups are byte-identical and the declared activation quantizer is independently applied to each identical group, their quantized Down input can also be shared across destinations. This can reduce repeated input preparation/posting, but not the distinct expert Down weight reads. If quantization instead uses an expert-global amax or applies alpha before quantization, that sharing assumption must be rederived. This is a dependency detail for formal thinking, not a new hardware/quality claim.

The bounded question is therefore real enough to think about: does a finite group pool reach a quality–capacity–whole-page point where joint route-union training matters and same-function host residency/ordinary-load does not already remove NAND relevance? Its answer remains unknown. A small bank, a quality-required near-disjoint pool, or equal results from a simpler overlap/width control are concrete veto regions. No experiment or source code is authorized by this judgment, and no old clock is transferred.
