Use m*S_ij to approximate alpha_i F_i+alpha_j F_j. Runtime graph on original topK selects disjoint edges; unmatched experts and original shared/dense branches execute normally. ## 21:00–21:03 UTC: a decisive separability objection to the concrete cheap student

Sol now recommends thought-rejecting the concrete tagged-feature publication claim. With J_i+J_j=J, the student is S=D'[t phi_i(x),(1-t) phi_j(x)]. Partition its Down columns D'=[D'_i,D'_j]. Then S=t D'_i phi_i+(1-t)D'_j phi_j. These are simply two partner-specific compact expert views, using exactly the same3H(J_i+J_j) raw coefficients. Giving the control equal physical copies, common row scales, host concat/tag modulation, dynamic A8 and a shared accumulation command can reproduce the candidate's deployed bit patterns and packed addresses. Forcing separate quantizers or separate commands only on the control would manufacture a difference. A ridge experiment against only a single CRISP prefix would therefore fail to identify new sensing work reduction.

This is not a universal theorem against conditional views or arbitrary nonlinear pair KD. A student with genuinely recombined nonlinear features could escape this particular separability identity, but there is currently no concrete mechanism or identifiable low-cost pilot showing why it would outperform the original-plus-low-rank/lowbit/lower-K alternatives. Failing a cheap tagged ridge implementation would not falsify that broad nonlinear hypothesis.
