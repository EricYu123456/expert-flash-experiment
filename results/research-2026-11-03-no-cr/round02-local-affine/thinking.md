## Concrete change in work

For layer input x, the host computes one shared coordinate z=P_l x, reusable by all original top-K experts and by their region selectors. Original routing, shared branch presence/absence, and architecture-specific scaling remain explicit. An expert assigned to a calibrated anchor c executes a stored local map A_e,c z+b_e,c, with a single ordinary in-flash matvec. Unsupported or low-confidence inputs select the original expert BEFORE either representation is read. This is an approximate operator; fallback at a later layer does not erase upstream approximation errors.

This changes both coefficients and dependency: the branch reads H*r coefficients instead of3H*I, and eliminates its GU→nonlinearity→Down flash barrier. It must still pay host projection, selector, bias/scales, A8 quantization, physical pages/commands, map storage, calibration and original fallback. No shared expert, CR, extra chip channels or free cache is needed by definition. Whether it preserves useful model quality is unknown.

For the continuous SwiGLU reference F=D[SiLU(Gx) elementwise(Ux)], the Jacobian at c is J(c)=D[diag(Uc*SiLU'(Gc))G+diag(SiLU(Gc))U]. With orthonormal P rows, an initializer is A_c=J(c)P^T and b_c=F(c)-A_c P c. Canonical W8A8 scale/round operations are nonsmooth; this derivative is only an approximation initializer, never a bit-equivalence claim. Local ridge/OLS can calibrate residuals, but any advantage of ordinary local regression must be admitted rather than credited to a new derivative formula.

## Potential separation and counterexamples

If each actionable input region has a low-rank tangent while slopes differ strongly across regions, one selected local map can model a nonlinear expert that a single same-read global affine map cannot. This is a constructed possibility, not evidence that real checkpoint states have a small covering number or low curvature. A common P restricts all local maps to one input subspace; discarded directions can remain important even when output tangents differ. Give global/local controls the same P and selector resources.

High-dimensional nearest-anchor distances may barely shrink. The special case c=0 has zero first derivative for bias-free SwiGLU, so a naive mean near zero can produce a useless tangent. A large bank could be prohibitively expensive to calibrate, choose or store; original routing domains are not automatically thin manifolds. A piecewise-constant cached output, single global ridge map, low-bit originals, low-rank/shared-basis FFN, selected-original-plus-residual, or simple lower-K execution may dominate. Only a quality/read Pareto comparison can decide.

Its claims of exact coordinate-variance/row-amplitude equalization need restriction: a Hadamard rotation gives equal variances for a diagonal covariance, or equality in expectation over suitable independent random signs; it does not exactly equalize an arbitrary conditional covariance with one fixed sign draw.
