# A direct conditional-latent control if Stage0 has a signal

Theory only, written after the thought gate while the executor implements Stage0. This does not alter the frozen Stage0 family or authorize data. It is a mandatory same-round follow-up question before any output-subspace or publication claim.

Local slopes winning against one pooled slope do not identify why they win. All regional maps might share one small output subspace and differ only in their latent input transform. That case admits a MoLAE-like implementation with cheap conditional host transforms and a single global output matrix per expert.

For a fixed expert and input format, write A_c approximately as U_q B_c. An unweighted SVD of the concatenation [A_1 ... A_C] is a simple reproducible control, but its coefficient metric can overemphasize directions scarcely visited by inputs. A stronger fit-weighted version forms M=sum_c p_c A_c S_c A_c^T, where S_c is the empirical centered design covariance under the declared calibration weights. The top-q eigenvectors of M minimize the squared discrepancy between A_c v and U_q U_q^T A_c v on this fitted distribution; B_c=U_q^T A_c realizes that projection. Keep each regional free intercept. This is a construction in real arithmetic, not a claim that W8/A8 quantization preserves it exactly.

The control can also fit/refine B_c directly against canonical teacher targets on FIT with the same ridge/VALID budget. No full-model SGD or knowledge-distillation pipeline is necessary just to ask whether the local bank is avoidable. A teacher- or regression-weighted basis and an unweighted coefficient basis are distinct declared estimators, not SCORE-driven choices. Freeze the chosen control family before any new held-out evaluation.

At Deep H2048, r128, C32,1664 routed experts, q128 requires about0.872decimalGB of W8 host B factors (or3.490GB F32), while all U factors require about0.436GB W8. Biases, scales, common P/tree, non-FFN weights and KV still count toward host8GB. This differs from the13.959GB local-A bank. Increasing q improves representational freedom but raises host transform capacity/traffic and decoder work; it is not a free same-wave rank increase.

Runtime pays K conditional small host matrix-vector products, per-expert latent A8, and actual input posting to legal chip groups before reading U_q. Those inputs differ across experts, so the primary bank's common broadcast advantage cannot be silently retained. Conversely, one-context-per-chip-group layouts can be legal without free K-context page buffers, and the control may cache U or even the full representation in host memory if the joint budget permits. Quantize B/U and remeasure actual outputs, including the additional latent quantizer and bias calibration. Real-valued SVD equality is not native arithmetic equality.

With a group-shared U, host live-alpha aggregation can happen before one output lift per active group; this stronger MoLAE-style option must receive the same capability and capacity. Regional host biases aggregate using the original route coefficients as well. A winning local map bank could still be valuable because it avoids host conditional work, input posts or a second quantizer, but those are empirical system explanations rather than a proof of rotating output subspaces.

This control is intentionally downstream of the bounded Stage0 screen. Stage0 positive only permits continued same-round work. It does not establish a whole-model quality/latency result, nor that the bank beats a nonlinear conditional latent control, W4 originals, lower-K or host-cache policies.

## C1 estimator-capacity interpretation

At C1, a finite local shrink-to-pooled fit need not equal the pooled single-ridge fit. If S is the common covariance and Cxy the cross statistic, A_p=(S+eta I)^(-1)Cxy and A_l=A_p+(S+lambda I)^(-1)(Cxy-S A_p). On eigenvalue d its filter is (d+eta+lambda)/((d+eta)(d+lambda)), generally not a single ridge1/(d+rho). Thus a C1-only gain is a global-surrogate regularization signal, not evidence that a conditional bank is necessary. A small C>1 gain may also partly reflect estimator capacity. The same-round positive expansion must give the global pooled slope the same two-stage eta/lambda correction ability, with the same contextual free biases, before attributing a difference to regional slopes.

This clarification does not weaken the frozen rule: a credible Stage0 nondominated point remains a reason to continue the same round. It is not silently reclassified as a valid experimental failure merely because C1 has no bank novelty. The bounded negative still concerns only the frozen operator loss/cost comparison. If later full-quality/whole-latency evidence supports a useful global engineering variant without publication value, report that result separately under the campaign's>=10percent whole-model engineering rule.
