# Gate-first A8 zero: primary-source review for Stage 0

Status: frozen at 2026-11-02 19:58 UTC, before any candidate probe; not a publication-approval gate. Source inspection is separate from the experimental protocol. No candidate code, model/activation probe, or numerical candidate experiment was performed in this research review.

| Primary source | What is actually established | Boundary relative to this candidate |
| --- | --- | --- |
| [AiF ISCA 2025, §4.3–4.4 and §5.2](https://doi.org/10.1145/3695053.3731073) | Be-encoded LSB needs one sense, reused latches hold the input, and ECC precedes on-chip INT8 products. Chip requests specify block, offset and contiguous page count. | No arbitrary page mask, raw-I32 output ABI, cross-command input persistence, or partial-sum continuation is disclosed. 16 KiB page is the nominal main scope; controller and added hardware need explicit costs. |
| [PowerInfer-2, §4.3–4.4](https://arxiv.org/html/2406.06282v2) | Predictor-selected Gate is computed; if its activation is zero, later portion of Q4 neuron bundle is not read. Cluster pipeline separates Gate reads/computation from later Up/Down reads. | Predictor may introduce approximation. Its 4 KiB describes UFS/OS logical read size, not verified NAND physical sensing. It does not present this dynamic-A8 witness certificate or AiF die MAC. |
| [CATS, Algorithm 1](https://zhang677.github.io/publications/cats2024.pdf) and [MoNE, Algorithm 1](https://arxiv.org/html/2510.05781v1) | Gate-first sparsification followed by selective Up/Down is established; MoNE also uses expert-internal selection. | These use approximate thresholds/ranking on an unchanged dense network, or a model explicitly trained for selected neurons. They are strong matched-quality alternatives, not exact W8A8 zero certificates. |
| [Park et al., §4 and Appendix B](https://arxiv.org/html/2605.08575v1) | vLLM GPU MoE integration evaluates standalone Gate plus masked sparse Up/Down and reports performance on Qwen3.5. | Accuracy is approximate; paper describes absolute activation threshold but printed kernel compares raw gate to a one-sided cutoff. Listed kernel does not by itself establish correct GPT-OSS clamp, offset and bias handling. |
| [SnaPEA, §3](https://cseweb.ucsd.edu/~vakhlagh/ISCA18-SnaPEA.pdf) | A sign-ordered partial accumulation can certify an exact ReLU zero and terminate the rest. | CNN/ReLU is not dynamic expert-wise A8 SwiGLU or flash; the general claim of exact early-zero detection is prior art. |
| [BitStopper, §III-B and §IV-B](https://arxiv.org/html/2512.06457v1) and [PADE, §IV-A/C](https://arxiv.org/html/2512.14322v1) | Partial bit-plane dot products, upper/lower residual bounds, a threshold derived from maximum lower bound, partial-state reuse and early termination of later memory reads. | Related author group and attention-pruning line, not independent studies. Threshold pruning is approximate relative to dense attention and is neither NAND nor the particular A8 zero contract. |
| [miniTE §5.6](https://www.lmsys.org/images/blog/minite/report.html) | Streaming MoE SwiGLU with online running amax and partial-scale compensation. | The report explicitly does not claim bit equality to two-pass full-row quantization. It is not gate-first Up skipping or AiF. |
| [SparQ §2.4](https://openreview.net/pdf?id=9wpm4fbBJI) | Quantization-induced zero activation sparsity is used to reduce communication in LLM split training. | A4 Llama result does not establish A8 DeepSeek/OLMoE zero rates, page co-sparsity, or witness effectiveness. |
| [SOML, ASPLOS 2019](https://www.cse.psu.edu/hpcl/docs/2019_ASPLOS_chun.pdf); [Micron B47T datasheet](https://static6.arrow.com/aropdfconversion/d0bac5f45ba8b58fcb4371e718e83027ba3d45b9/b47t-media-die-512gb-addendum.pdf) | SOML investigates concurrent subpage reads with physical extra selector/decoder changes; B47T exposes fixed ~8 KiB+ IWL sections and distinct timing/mode restrictions. | Neither establishes native 4 KiB independent sensing in AiF. Stage 0's 4 KiB unit is hypothetical sensitivity only, not a measured or native-device prediction. |
| [MoNE Fig. 2 / Appendix A.2.1](https://arxiv.org/pdf/2510.05781) | Gate-factor distribution of specific DeepSeek-V2-Lite experts/layers is shown. | Aggregate selected-magnitude thresholds do not give per-token amax-relative zero-certification or whole-page rates. |

Stage 0's exact contract is the specified CPU W8A8 graph with its actual per-expert activation domain, original per-model activation and routing order, float rounding, and I64 dot. It is not original GGUF accuracy, native AiF execution, FP8/MXFP4 equivalence, device speedup, or scientific proof of sample generality. Shadow A6/A4 diagnostics do not establish their own end-to-end quality or speed.

In the local pinned llama.cpp, both nominated routed graphs use `ggml_swiglu_split`, and `ggml/src/ggml-cpu/vec.cpp` selects an ISA-specific vector `ggml_v_silu`, followed by multiplication, with scalar code only for the tail. The standalone `ggml_vec_silu_f32` shares the corresponding ISA path; the gate factor used for a certificate must come from the exact same compiled implementation, row length and execution mode, and its reconstructed product must be checked against the actual fused graph. An independently computed scalar `expf` is not presumed bit-identical. Record compiler flags, FTZ/rounding and selected CPU backend. The DeepSeek GGUF graph has one leading dense layer and a single shared-width 2816 branch in each MoE layer; do not silently split the latter into separate 1408-wide quantizer domains.

Controls must include full dense, dense Gate+Up plus identical post-A8 sparse Down, and already-exact gate-zero skipping. To count new complete read units, compare all baseline `gate_zero` pages against candidate `gate_zero OR certified` pages, excluding all actually paid witness pages from candidate skips. Mixed gate-zero/certified pages must be counted; a baseline may also skip a page that the candidate paid for as a witness. Keep same layout, hardware, capacity, precision, and activation semantics for each exact comparison. Page and coefficient work are not read-wave critical-path latency.

Potential positive results require later evaluation against model-matched CATS/Park/SLIM and strong sparse layouts under equal quality and hardware. Some publications are read through abstracts only where the detailed text is unavailable; that is an explicit publication-stage limitation, not a prerequisite to this bounded training-only falsification.
