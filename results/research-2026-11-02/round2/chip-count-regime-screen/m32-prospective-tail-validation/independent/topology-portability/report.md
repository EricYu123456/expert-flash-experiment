Cambricon details useful for a necessary headroom screen:

- Table II: 16KiB page, 30µs read latency, 1000MT/s × 8-bit channel bus (derived 1GB/s raw interface), one compute core per die; S has four cores/channel.
- IV-B: one-page read-compute; array → data register → cache register → PE, allowing the register stages to pipeline requests. Input is loaded into the core input buffer; completed vector goes to output buffer and NPU. The 20µs/2-MAC example is illustrative, not the Table II 30µs configuration or an additional throughput calibration.
- VII-C gives **2KB combined input/output buffer**, without an input/output split. It does not support assigning AiF's input-buffer bound here.
- V-A/ VIII-C: the S global tile is 256×2048, split into **64×256 atomic matrices** per core. Columns split across eight channels; rows split across four cores within a channel. Broadcasting eliminates repeated common-input transmission on that channel. This is already a strong native tiling/input-affinity control.
- Default W8A8 and the VIII-B W4A16 experiment are explicit. Accumulator/output width, scaling/rounding, reset, multi-page row continuity, edge-fringe handling and a public command ABI are not. External partial-sum numerical compatibility is not established by the real-valued matrix partition.
- V-B partitions weight work between flash read-compute and ordinary reads for NPU computation. It does not specify a second full coefficient image. VI separately protects approximately the largest 1% of values using two spare-area copies; the paper reports 722B ECC metadata within 1664B spare bytes per page. This is not a replicated tensor layout.
- VIII-E's 128 is **chips per channel** in an 8-channel sweep, not 128 total chips. The study also states that buffer area and chiplet geometry constrain scaling.

Pure coefficient-capacity necessary bounds for 32 cores and 16KiB atomic pages are in `notes.json`. Per expert, G4 GU/Down have 96/48 useful pages (pooled depth lower bounds 3/2); Deep GU/Down have 352/176 (11/6). These are **not feasible native multi-page row certificates, full timing lower bounds, or predicted speeds**. A matrix row that straddles atomic pages requires a documented composition contract before using it as an opaque complete-row job.

All four sources describe modeled architectural designs and/or synthesized blocks, not fabricated commercial NAND compute chips. No integrated author functional/timing artifact was verified in this bounded pass; stored primary HTML hyperlinks and existing evidence were inspected. This is an availability limitation, not proof no artifact exists. No new capture payload/routes/results, old test, checkpoint or inference was accessed.
