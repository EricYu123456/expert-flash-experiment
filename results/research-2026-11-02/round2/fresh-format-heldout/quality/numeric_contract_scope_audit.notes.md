The teacher-quality quantization scope is independent of physical row-job configuration. This audit reads existing frozen source/cache artifacts and does not run inference or quantization again.

The already frozen `quality-build/unchanged_numeric_contract.json` certifies seven old/new function bodies byte-for-byte: quantize, dot, scale_output, equal_bits, target selection, weight cache and the W8A8 operator audit. The teacher C++ implementation uses a cache key of weight name and expert ID, with no token, activation, chip or native-job field. On its first use, each complete original GGUF row is dequantized with the original type's to_float function, then quantized across all C columns to fixed row-W8 bytes and an F32 row scale. Chip assignment and packing occur afterward, copying the same bytes/scales. Subsequent uses return the cached expert/projection entry without re-quantizing weights.

The observed caches corroborate this source path. All 7,515 fresh teacher expert/projection entries also occur in fresh generation. Their canonical W8 byte hashes, row-scale hashes, dimensions, original types and source offsets match; all 6,453,760 F32 row-scale elements are byte-identical, totaling 25,815,040 compared bytes. Earlier train versus fresh teacher and fresh generation comparisons likewise match over their 7,161 and 7,269 common entries. No source scale was selected based on the fresh inputs.

A8 deliberately depends on the actual whole activation vector. `audit` allocates q and sx for T×V vectors, calls quantize over the full original C-vector once per vector before selecting experts or looping output rows, then every canonical/packed full-row dot reuses those same bytes and scale. There is no per-chip/per-row/native-job A8 quantization or column-partition-dependent normalization. For routed down V=6; gate/up and shared inputs use V=1. Separate gate and up operator invocations each quantize their identical full input; this is not a claim of a single global quantization across different logical operators.
