This is an executable address and numerical proof for Granite4 Tiny's isolated layer0 FFN, with all64 routed experts and the always-active shared FFN physically materialized. It validates the functional raw-W8A8 CPU reference and row relocation; it is not original-GGUF numerical equivalence, native AiF format proof, hardware timing, routing revalidation, or quality evidence.

The source is the existing readonly Q4_K/Q6_K GGUF. Every logical row is dequantized with the pinned local GGUF package, then fixed once to signed[-127,127] with F32 maxabs/127 and half-away rounding of the F32 normalized value. Original per-block quantization is therefore replaced in this explicit functional reference. Logical row scales remain at the host and are shared between both layouts. Full activation vectors are quantized once, with the same bytes reused across whole-output-row shards. Integer CPU dots are converted once to F32 and scaled by F32(rowScale×inputScale).

There are two sets of16 virtualchip binary files. Addresses explicitly identify block, wordline and plane:192 wordlines/block,4 planes/wordline,16KiB/page. Every matrix run begins at plane0, covers complete output rows, and stays inside one block. The interpreter recomputes physical addresses from these geometry fields before pread. This is a reproducible virtual controller mapping; the real aif_post ABI and actual NAND execution are not asserted. Both layouts reserve one12MiB block per chip,192MiB per layout, with padding included in file hashes.

The source layout stores148.5MiB useful weights/9504pages. The paired-shared layout stores151.5MiB/9696pages; the extra3MiB is explicitly counted, while the reserved block capacity remains192MiB in this one-layer allocator. The latter stores each shared128-row tile and its paired neighbor as a contiguous256-row chunk at both paired owners. Its legal views compute both rows at either owner, or one128-row tile at each owner. There are no copied routed weights, omitted weights, partial dots, decoded parity, extra native context, or duplicated computation of a logical output row. All1312 stored allocations in each layout were read back, hashed, checked against the canonical weights and audited for physical disjointness and logical row coverage.

The seven selected top-6 routes are the first training route at every observed half-A count0…6. Inputs are explicit F32 PCG64(seed20261102) standard-normal fixtures; coefficients are explicitly F32[1,2,3,4,5,6]/21, not saved router scores. These are fixed across all layouts. Each fixture runs the baseline and four paired-shared policies, covering every pair's three legal choices and a mixed-pair policy. The reference reconstructs gate/up logical row order, completes the whole expert GU, applies SwiGLU, quantizes the full private down vector512 or1024, computes down, then combines in the saved selected expert order and adds shared output. All35 cases and860160 scalar outputs are bitwise equal to the unsharded functional reference. Every safe-I32 dot is also checked.

A separate process imports none of the materializer, retains none of its canonical weight arrays, and loads only saved manifests, scales and fixtures. It reads each16KiB plane page separately and uses I64 dots instead of I32. Its490 matrix phases and860160 scalar comparisons match the baseline and saved reference outputs exactly. The native output dtype/scales contract remains unproven regardless of this CPU agreement.
