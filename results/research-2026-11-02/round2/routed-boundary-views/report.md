Each routed expert GU has three101-row chips, eleven75-row chips and two76-row chips. Swapping high source s with low target t moves25/26 complete rows. Store donor core followed by its packet at s, and target core followed by a copy of the packet at t. View A executes the donor's long prefix and target's short prefix; B executes donor short and target long. The latter's useful outputs correspond to `target-core logical IDs + donor-suffix logical IDs`, requiring a two-segment host row map rather than reassigning logical IDs by chip-order rowcounts. Independent symbolic reconstruction verifies every useful logical row appears exactly once in each view; the packet alone is stored twice.

Useful-result uniqueness does not mean every hardware row computes once: a75-row short prefix reads12pages and emits76 complete outputs, so it can compute a discarded packet row as fringe. Long101-row jobs read16pages and emit102 outputs. These extra outputs are charged.
