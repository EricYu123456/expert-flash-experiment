# Simple balanced-wave attribution control

All frozen winners in the three audited campaigns are covered by cyclic/disjoint geometries plus a simple balanced-wave tiler. The independent row allocation uses round-robin row filling and does not import the DP/compiler. Canonical fits, shared mapping and relative rotations are reused without extra seeds.

This does not establish an algorithmic advantage from DP/frontier/branch-and-bound, nor negate a narrower system contribution. No heldout input was used. See summary.json for exact coverage, input hashes and limitations.
