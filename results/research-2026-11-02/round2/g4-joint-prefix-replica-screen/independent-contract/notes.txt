Two fixed images; separate logical dimensions
---------------------------------------------
For each routed expert GU consumes1024original rows (512gate+512up) with full
common1536-element input. Down consumes1536original output rows with full private
512-element input after the entire expert's unique GU outputs, host SwiGLU and
complete-vector dynamic A8. Shared remains unchanged (including its own private
input dimension). GU/Down have different logical namespaces; their row counts
must not be combined into a fictitious operator dimension.

GUlayout3 has eight source chips with original82/83core followed by copies to
128rows. Seven sources append one low40range and a5/6row piece of the original
high-destination prefix. The special source appends the45/46row high suffix.
The original low/high destination weights remain resident. Independent u_i:
source reads core or128; matching low job disappears iff u_i=1. High destination
reads full82/83 if specialu7=0, prefix36/37/38 if specialu7=1 but not allu, and
no job if all8u=1. z=AND8u is required; z cannot be independently selected.
Copied high-prefix rows can still be computed at the original high destination.
Host consumes exactly one owner per original row and drains/drops duplicates.

GU meaningful computed row count can exceed1024; emitted page-fringe count can
exceed that. Both are billed. A short82/83source reads8pages and emits85complete
rows plus512B partial next row; real copied fringe is dropped. A short high
prefix36..38reads4pages and emits42complete rows plus1024B partial tail, which
can include real stored original high-suffix rows. Low40 reads4pages and has
padding fringe. Long128 is exact12pages/3waves. No validR, skipped MAC, row-stop
or partial output contribution is assumed. Immutable row scales remain indexed
by original expert/gate-up/logical row rather than computed or physical index.

Down14 pairs the12positive128row chips into6fixed directed source/dest edges.
Dest128core plus copied source128suffix is resident; source128 remains stored.
v=0 executes128+128, v=1 executes0+256. Each view consumes1536unique rows with
12waves and6..12jobs. C512 makes128/256exact1/2waves; no Down fringe/partialrow.
All copied Down rows reference the original expert/Down/logical-row scale.

The images are fixed offline. Runtime chooses u/v prefix views, not alternative
physical pairings or addresses. GU and Down phase legality forms a Cartesian
product because each phase individually covers its own full logical outputs
and the whole-GU/private-Down barrier is preserved. This establishes legal
composition, not additive latency or a new replication/selector theorem.
