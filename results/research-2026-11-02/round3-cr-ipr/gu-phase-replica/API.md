# GU replica builder API

The frozen modules build real physical pages; they do not calculate fullFFN cost or change any tensor value. All GU pages contain W8 coefficients, 16,384 bytes/page, with 1,536 bytes per complete output row. Two other PB latches retain the common input.

`phase_builder.build_fixedphase_split(route)` returns a dictionary containing `waves`, `assignment`, `owner_ranks`, `metadata`, and the true unselected resident `pool`. Use the returned waves with the sealed simulator and **source_policy='fixed'**, copy500, strict_no_interval, and conditional pre-ECC drop. It has 13 physical waves and 48 useful pages. `build_fixedphase_plain(route)` returns the unshaped 12-wave stream; copy100 passes without any drop, while copy500 fails. `build_layout()` returns all744 resident pages/chip, including the logical source page, phase copy, block, plane, and WL.

`group_builder.build_fixedgroup_split(route, group=chip//8)` has the same return fields. Routed experts have128 complete rows/chip on eight chips, rather than64 rows/chip on sixteen chips. Shared GU remains128 rows/chip on all sixteen chips. `build_layout(group=None)` returns templates for groups0 and1; supply a group to obtain one template. The primary split uses IPR because dummy pages have their own true WL addresses.

`group_builder.build_fixedgroup_whole_dummy(route, group=chip//8)` is a separate standard same-WL control. Every physical wave, including the all-dummy wave, reads four planes at one WL. It needs skip-WL CR and conditional pre-ECC drop, and does not need IPR or programmable PB source. The all-dummy wave has `pages=[]` and four real `read_pages`; the sealed simulator rejects this input domain. Use the explicitly restricted `all_dummy_reference.simulate_fullplane(waves, cache_copy_ns=500)` for this control. It returns page completions, resource events, latch violations, and a155680ns makespan. Its nonempty-wave behavior matches the sealed simulator exactly in432 saved bridge cases.

For the group template, expert source byte offsets are relative to the128-row shard at `chip%8`; for phase replicas they are relative to the64-row shard at `chip`. Shared offsets are relative to the128-row shard at `chip` in both cases. Across a complete expert tensor, both copies refer to identical logical source coefficients. Dummy pages have a distinct read identifier but retain their underlying source-page and physical-copy identifiers.

Exclusive experts0,1,2 belong only to phase/group0; experts3,4,5 belong only to phase/group2/1. All remaining58 experts have two complete copies. `assign_phases(route)` first assigns exclusive experts, fills the remaining phase0 capacity with sorted dual experts, and assigns the rest to phase2. Exactly three experts occupy each side for every top6 route. The phase builder interleaves the two sorted lists and consumes each expert's full six pages; the group builder consumes each side's three complete twelve-page experts. Shared pages always follow.

Pre-ECC drop remains conditional. These are known two-server capacity3 CBC / standard group replication controls applied to physical placement. Neither an additional PE selector nor algorithmic novelty is claimed. FullFFN replay and independent numerical interpretation are separate artifacts.
